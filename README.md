# municipality-car

全国の市区町村別に中古車買取・査定情報を整理する地域データサイト。

## 実装方針
- 全国47都道府県・市区町村をVercelビルド時に自動生成
- トヨタ現行車・主要旧車の車種ページ
- 市区町村別の売却・査定チェックポイント
- SEO / AIO / LLMO: canonical, sitemap, robots, JSON-LD, llms.txt
- UGC: 査定体験・口コミUI（配布版はlocalStorage）
- 公的・公式一次情報を優先し、架空の買取相場は掲載しない

車種情報はトヨタ自動車公式ラインアップ・認定中古車の車種情報を参照します。
